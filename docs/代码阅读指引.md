## 常见问题解答

### Q1: 构建失败怎么办？

**问题**：`colcon build`报错

**解决步骤**：
```bash
# 1. 清理构建
cd /home/orin/Workspace/agri_ugv/ros2_ws
rm -rf build install log

# 2. 重新构建
colcon build --symlink-install

# 3. 查看详细错误
colcon build --symlink-install --event-handlers console_direct+
```

**常见原因**：
- 依赖未安装：检查`package.xml`中的`<depend>`标签
- 路径错误：确保在正确的工作空间目录
- 编译器问题：确保安装了`colcon`和ROS2编译工具

### Q2: 找不到话题/节点？

**问题**：`ros2 topic list`看不到期望的话题

**检查步骤**：
```bash
# 1. 检查节点是否运行
ros2 node list

# 2. 检查节点状态

# 3. 检查话题是否隐藏（默认隐藏）
ros2 topic list --include-hidden-topics
```

**可能原因**：
- 节点未启动
- 节点启动失败（查看日志）
- 话题在namespace下（如`/revo/pose` vs `/pose`）

### Q5: 如何理解Python的rclpy？

**基础概念**：
```python
import rclpy
from rclpy.node import Node

class MyNode(Node):
    def __init__(self):
        super().__init__('my_node')
        # 创建发布者
        self.publisher = self.create_publisher(String, 'topic', 10)
        # 创建订阅者
        self.subscription = self.create_subscription(
            String, 'topic', self.callback, 10
        )
        # 创建定时器
        self.timer = self.create_timer(1.0, self.timer_callback)

    def callback(self, msg):
        print(f"收到消息: {msg.data}")

    def timer_callback(self):
        msg = String()
        msg.data = "Hello"
        self.publisher.publish(msg)

def main():
    rclpy.init()
    node = MyNode()
    rclpy.spin(node)  # 阻塞，运行节点
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

### Q6: 如何理解C++的rclcpp？

**基础概念**：
```cpp
#include <rclcpp/rclcpp.hpp>
#include <std_msgs/msg/string.hpp>

class MyNode : public rclcpp::Node {
public:
    MyNode() : Node("my_node") {
        // 创建发布者
        publisher_ = this->create_publisher<std_msgs::msg::String>("topic", 10);

        // 创建订阅者
        subscription_ = this->create_subscription<std_msgs::msg::String>(
            "topic", 10,
            std::bind(&MyNode::callback, this, std::placeholders::_1)
        );

        // 创建定时器
        timer_ = this->create_wall_timer(
            std::chrono::seconds(1),
            std::bind(&MyNode::timer_callback, this)
        );
    }

private:
    void callback(const std_msgs::msg::String::SharedPtr msg) {
        RCLCPP_INFO(this->get_logger(), "收到消息: %s", msg->data.c_str());
    }

    void timer_callback() {
        auto msg = std_msgs::msg::String();
        msg.data = "Hello";
        publisher_->publish(msg);
    }

    rclcpp::Publisher<std_msgs::msg::String>::SharedPtr publisher_;
    rclcpp::Subscription<std_msgs::msg::String>::SharedPtr subscription_;
    rclcpp::TimerBase::SharedPtr timer_;
};

int main(int argc, char** argv) {
    rclcpp::init(argc, argv);
    auto node = std::make_shared<MyNode>();
    rclcpp::spin(node);
    rclcpp::shutdown();
    return 0;
}
```
