## 项目概览

### 项目背景
我们正在开发一个基于ROS2的农业无人车(UGV)系统，该系统能够控制两种不同类型的农业机器人平台：

1. **XAG Revo R100/R200** - 专业农业机器人平台
2. **Agilex Hunter SE** - 通用移动机器人平台

### 项目目标
- 实现两种机器人平台的统一控制
- 开发高精度的自主导航系统
- 集成多种传感器实现环境感知
- 构建完整的智慧农业解决方案

```bash

#### 4. 依赖安装

# 安装其他依赖
sudo apt install git python3-rosdep python3-vcstool
rosdep init
rosdep update
rosdep install --from-paths src --ignore-src -r -y
```

### 第一个ROS2节点

#### 1. 创建Python节点
```python
# 在 revo_ugv_ros2/revo_ugv_ros2/ 创建 hello_world.py
import rclpy
from rclpy.node import Node

class HelloWorldNode(Node):
    def __init__(self):
        super().__init__('hello_world_node')
        self.timer = self.create_timer(1.0, self.timer_callback)
        self.count = 0

    def timer_callback(self):
        self.get_logger().info(f'Hello World! Count: {self.count}')
        self.count += 1

def main(args=None):
    rclpy.init(args=args)
    node = HelloWorldNode()
    rclpy.spin(node)
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

#### 2. 修改setup.py
```python
# 在 revo_ugv_ros2/setup.py 的 console_scripts 中添加
entry_points={
    'console_scripts': [
        'hello_world_node = revo_ugv_ros2.hello_world:main',
        # ... 其他入口点
    ],
},
```

#### 3. 编译和运行
```bash
# 编译
colcon build --packages-select revo_ugv_ros2

# 运行
source install/setup.bash
ros2 run revo_ugv_ros2 hello_world_node
```

## 开发流程

### 1. Git工作流

#### 分支策略
```
main            # 主分支，稳定版本
├── develop      # 开发分支
├── feature/*     # 功能分支
├── hotfix/*     # 紧急修复
└── release/*    # 发布分支
```

#### 提交规范
```bash
# 提交格式
<type>(<scope>): <description>

# 类型说明
feat: 新功能
fix: 修复bug
docs: 文档更新
style: 代码格式化
refactor: 重构
test: 测试相关
chore: 构建或工具变动
```

#### 代码提交流程
```bash
# 1. 创建功能分支
git checkout -b feature/your-feature-name develop

# 2. 开发和提交
git add .
git commit -m "feat(revo): add new sensor interface"

# 3. 推送到远程
git push origin feature/your-feature-name

# 4. 创建Pull Request
# 在GitHub上创建从feature分支到develop的PR

# 5. 代码评审
# 等待团队成员审核并合并
```

## 常见问题

### 开发环境问题

#### Q1: ROS2工作空间编译失败
```bash
# 解决方案
rm -rf build/ install/ log/
colcon build --symlink-install
```

#### Q2: CAN设备无法识别
```bash
# 检查USB转CAN设备
lsusb

# 加载驱动
sudo modprobe gs_usb

# 检查can0接口
ip link show can0
```

#### Q3: 传感器话题没有数据
```bash
# 检查节点运行状态
ros2 node list

# 检查话题发布
ros2 topic echo /scan -n 1

# 检查设备连接
ls /dev/ttyUSB*
```

### 代码问题

#### Q1: Python包导入错误
```bash
# 确保工作空间已source
source install/setup.bash

# 检查Python路径
python3 -c "import sys; print(sys.path)"
```

#### Q2: C++编译错误
```bash
# 清理编译缓存
rm -rf build/hunter_base/

# 重新编译
colcon build --packages-select hunter_base --symlink-install
```

### 运行时问题

#### Q1: 机器人不动
```bash
# Hunter检查
candump can0  # 查看CAN帧
ros2 topic pub /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.1}}"

# Revo检查
ping 192.168.234.1  # 检查网络连接
```

#### Q2: 导航失败
```bash
# 检查地图
ros2 run nav2_map_server map_saver_cli -f ~/map

# 检查TF
ros2 run tf2_ros tf2_echo odom base_link

ros2 topic echo /nav2/status -n 1
```
