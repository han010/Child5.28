# 农业UGV功能模块说明

## 项目概述

本项目是基于ROS2的农业无人车(UGV)系统，结合XAG Revo R100/R200和Agilex Hunter SE两个机器人平台，实现户外农业场景下的自主导航和作业功能。

---

## 1. 导航模块 (Navigation)

### 1.1 技术方案
- **导航框架**: ROS2 Navigation2 (Nav2)
- **支持的运行模式**:
  - 室内自主导航 (基于SLAM地图)
  - 室外GPS航点导航
  - 混合场景导航 (室内外切换)

### 1.2 核心组件

#### Nav2导航栈
```
planner_server:     全局路径规划 (使用NavFn/Smac Planner)
controller_server:  局部路径跟踪 (DWB/TEB控制器)
behavior_server:    行为树管理 (恢复行为、任务规划)
smoother_server:    路径平滑优化
```

#### 导航配置文件
- `revo_ugv_ros2/config/nav2/nav2_params.yaml` - Nav2参数配置
- `revo_ugv_ros2/config/nav2/` - 行为树和代价地图配置

### 1.3 启动方式

**Revo室内导航:**
```bash
ros2 launch revo_ugv_ros2 revo_navigation.launch.py
```

**Revo SLAM建图:**
```bash
ros2 launch revo_ugv_ros2 revo_bringup.launch.py
ros2 launch revo_ugv_ros2 revo_slam.launch.py
```

**Hunter SLAM:**
```bash
ros2 launch hunter_base hunter_slam.launch.py
```

### 1.4 话题接口
| 话题名称 | 消息类型 | 方向 | 说明 |
|---------|---------|------|------|
| `/goal_pose` | `geometry_msgs/PoseStamped` | 输入 | 导航目标点 |
| `/cmd_vel` | `geometry_msgs/Twist` | 输出 | 速度控制命令 |
| `/odom` | `nav_msgs/Odometry` | 输入 | 里程计数据 |
| `/scan` | `sensor_msgs/LaserScan` | 输入 | 激光雷达数据 |

## 2. 定位模块 (Localization)

### 2.1 融合定位方案

系统采用多传感器融合定位，根据场景自适应调整权重：

```
           ┌─────────────────┐
           │   里程计 Odometry │
           │   (高频基础定位)  │
           └────────┬─────────┘
                    │
        ┌───────────┴───────────┐
        │                       │
┌───────▼────────┐    ┌────────▼────────┐
│   GPS/GNSS     │    │  激光雷达匹配   │
│  (户外高权重)   │    │  (室内高权重)   │
└────────────────┘    └────────────────┘
        │                       │
        └───────────┬───────────┘
                    │
            ┌───────▼────────┐
            │  EKF融合定位    │
            │  (robot_state_  │
            │   publisher)    │
            └─────────────────�
```

### 2.2 定位传感器

#### 2.2.1 GPS/GNSS定位
- **ROS包**: `revo_ugv_ros2/revo_gnss_node.py`
- **输入**: XAG Revo底盘GNSS数据
- **输出**:
  - `/gps/fix` (sensor_msgs/NavSatFix) - GPS位置信息
  - `/gps/fix_velocity` - GPS速度信息

**特性**:
- 户外场景主导定位源
- 提供绝对坐标和航向
- 与UTM坐标系转换集成

#### 2.2.2 激光雷达定位
- **ROS包**: `slam_toolbox` (SLAM) / `amcl` (定位)
- **雷达**: RPLIDAR A1 (单线机械雷达)
- **输出**:
  - `/scan` (sensor_msgs/LaserScan) - 原始扫描数据
  - `/map` (nav_msgs/OccupancyGrid) - 栅格地图
  - `/amcl_pose` - 定位位姿估计

**特性**:
- 室内场景主导定位源
- 点云匹配算法 (AMCL粒子滤波)
- 建图与定位模式切换

#### 2.2.3 里程计
- **ROS包**: `revo_ugv_ros2/revo_odom_node.py`
- **数据源**: XAG Revo底盘编码器 + IMU
- **输出**:
  - `/odom` (nav_msgs/Odometry) - 融合里程计
  - `TF: odom -> base_footprint`

**特性**:
- 高频 (50Hz) 基础定位
- 与雷达/GPS数据EKF融合
- 平滑处理减少抖动

### 2.3 场景自适应权重策略

```python
# 伪代码示意
定位权重策略:
    if GPS信号质量 > 阈值 and 雷达匹配置信度 < 阈值:
        # 户外场景：GPS主导
        GPS权重 = 0.7
        雷达权重 = 0.2
        里程计权重 = 0.1
    elif 雷达匹配置信度 > 阈值:
        # 室内场景：雷达主导
        GPS权重 = 0.1
        雷达权重 = 0.7
        里程计权重 = 0.2
    else:
        # 过渡区域：均衡配置
        GPS权重 = 0.4
        雷达权重 = 0.4
        里程计权重 = 0.2
```

## 3. 雷达模块 (Perception)

### 3.1 激光雷达 (LiDAR)

**硬件**: RPLIDAR A1
- **类型**: 单线机械雷达
- **扫描范围**: 360°, 12米
- **扫描频率**: 5-10 Hz
- **ROS驱动**: `rplidar_ros`

**启动**:
```bash
ros2 launch rplidar_ros rplidar_a1.launch.py
```

**话题**:
- `/scan` (sensor_msgs/LaserScan) - 激光扫描数据

**应用场景**:
- 室内SLAM建图
- 2D障碍物检测
- 局部路径规划

### 3.2 毫米波雷达 (mmWave Radar)

**硬件**: Wheeltec MR20
- **类型**: FMCW毫米波雷达
- **探测范围**: 0.2-10米
- **ROS驱动**: `wheeltec_radar`

**启动**:
```bash
ros2 launch wheeltec_radar wheeltec_radar.launch.py
```

**话题**:
- `/mmwave radar` - 雷达目标列表
- `/radar_tracker` - 目标跟踪数据

**应用场景**:
- 动态障碍物检测
- 速度测量 (多普勒效应)
- 恶劣天气 (雨/雾/尘) 补偿

### 3.3 深度相机方案 (待验证)

> **实验性方案**: 探索使用深度相机 + 毫米波雷达替代激光雷达的降本方案

**硬件**: 奥比中光 (Orbbec) 深度相机
- **型号**: 待补充 (如 Femto Bolt/Dabang 等)
- **深度范围**: 0.3-10米
- **RGB分辨率**: 1920x1080
- **深度分辨率**: 640x480

**ROS驱动**: 待集成
```bash
# 计划集成
ros2 launch orbbec_camera driver.launch.py
```

**预期话题**:
- `/camera/color/image_raw` - RGB图像
- `/camera/depth/image_raw` - 深度图像
- `/camera/points` - 点云数据
- `/camera/depth_registered/points` - 配准后点云

**方案对比**:

| 特性 | 激光雷达方案 | 深度相机+毫米波方案 |
|------|-------------|-------------------|
| 成本 | 高 (数千元) | 低 (千元级) |
| 室外性能 | 优秀 (受光照影响小) | 相机受阳光干扰 |
| 深度精度 | cm级 | dm级 (随距离衰减) |
| 多目标检测 | 一般 | 优秀 (视觉+雷达融合) |
| 夜间运行 | 支持 | 需主动补光 |
| 适用场景 | 已验证方案 | 待验证 |

## 4. 相机模块 (Vision)

### 4.1 当前配置

**硬件**: 奥比中光深度相机
- **ROS驱动**: `v4l2_camera` (基础) / Orbbec SDK (待集成)

**Revo相机节点**:


**话题**:
- `/camera/image_raw` - 原始图像
- `/camera/camera_info` - 相机标定信息

### 4.2 相机标定

```bash
# 相机标定
ros2 run camera_calibration cameracalibrator \
  --size 8x6 \
  --square 0.108 \
  image:=/camera/image_raw
```

### 4.3 TF坐标系

```
base_footprint (原点)
    └── base_link
        └── camera_link (0.4, 0.2, 0.16)
```

## 7. 运行清单

### 7.1 启动前检查

- [ ] Hunter SE: CAN总线已启动 (`bringup_can2usb_500k.bash`)
- [ ] Revo: 网络连接正常 (`ping 192.168.234.1`)
- [ ] 雷达: USB设备已连接 (`ls /dev/ttyUSB*`)
- [ ] 相机: 设备已识别 (`ls /dev/video*`)

### 7.2 快速启动

**完整启动 (Revo):**
```bash
# 终端1: 启动所有传感器和底盘
ros2 launch revo_ugv_ros2 revo_bringup.launch.py

# 终端2: 启动导航
ros2 launch revo_ugv_ros2 revo_navigation.launch.py

# 终端3: 键盘控制 (备用)
ros2 run revo_ugv_ros2 revo_teleop_keyboard
```

```bash
# 默认端口 8765
```
